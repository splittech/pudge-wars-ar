# Стиль EditMode-тестов

Тесты находятся в Assets/Game/Tests/Edit Mode. Принят стиль примеров разработчика:

- Имена: Method_Condition_ExpectedResult.
- Явные блоки комментариев на английском: Arrange, Act, Assert; для исключений — Act and Assert.
- Создание общих конфигураций, состояний, симуляции и зависимостей — через фабрики Setup с именованными параметрами и out-перегрузками.
- Один сценарий на тест; связанные свойства результата могут проверяться вместе. Независимые действия разделяются на отдельные тесты.
- Повторяющиеся входные варианты оформляются TestCase.
- Действие выполняется отдельно от Assert.That. Исключения проверяются через Throws.TypeOf<T>. Вызовы интерфейсных зависимостей проверяются Received / DidNotReceive.
- Unity-объекты и подписки освобождаются в TearDown. InputTestFixture сохраняет изолированное окружение Input System.

Фабрики Setup создают интерфейсные зависимости через NSubstitute и не содержат утверждений. Жесты публикуются через реальные Subject<T>, возвращаемые фабрикой через out-параметры. Результаты методов с out-параметрами задаются через Returns. Конкретный TestLoadingScreen находится в Assets/Game/Tests/Support (Game.Tests.Support). Сборка включается при UNITY_INCLUDE_TESTS и допускает AddComponent, в отличие от editor-only сборки. Он проверяет реальное поведение базового экрана загрузки; ручные двойники интерфейсов удалены. Подписки и Subject<T> освобождаются в TearDown.

Геометрия разделена на Geo2DTests, Rect2Tests и ArenaBoundsTests. Движение изолированно проверяется в HeroMovementTests, взаимодействие систем — в MatchSimulationTests. ConfigTests, SimulationDataTests и LoadingScreenTests проверяют свои контракты отдельно.

Запуск: Test Runner в открытом редакторе; при закрытом редакторе — unity test --mode EditMode.

HookNetStateTests проверяет вычисление кончика во всех фазах, ограничение дальности и возврат без перелёта владельца. Round-trip явно вызывает WriteHookNetState/ReadHookNetState для TargetNetId = 0/42/uint.MaxValue и проверяет все поля, 41 байт и отсутствие непрочитанных данных. Generic Write<T>/Read<T> не используется в этом unit-тесте: делегаты Mirror могут не быть зарегистрированы в EditMode. Явные readers/writers фиксируют порядок и размер полей независимо от приоритета встроенных varuint-сериализаторов.

NetworkPrefabFactoryTests проверяет local ServerToClient NetworkTransform на префабе, сохранение HookNetState во время одной фазы, экспорт TargetNetId вместо SessionPlayerId и реактивный HP после попадания. Ручная MPPM-приёмка визуальной синхронизации 2.5 подтверждена разработчиком 10.11.2026.

Если прогон в открытом Editor остаётся running, проверить диалог Scene(s) Have Been Modified: Unity Test Runner вызывает SaveCurrentModifiedScenesIfUserWantsTo перед выполнением тестов. По разрешению разработчика Codex может выбирать Save или заранее сохранять открытые сцены; Don't Save требует отдельного указания. После подтверждения Save прогон завершился успешно, после очистки Boot Scene оставалась чистой. Наличие Edit Mode не отменяет диалог сохранения.
