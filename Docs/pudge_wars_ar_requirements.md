# Pudge Wars AR — требования к курсовому проекту

## 1. Введение

В перечень вошли 23 требования, которые обязательно реализуются в MVP: 4 бизнес-требования, 15 функциональных и 4 нефункциональных. Уровни и типы требований — по разделу 2.2.4 учебника С. Куликова «Тестирование программного обеспечения. Базовый курс». Пороги выбраны с запасом, каждое требование проверяется сценарием на двух телефонах, автотестом или счётчиком отладочного оверлея.

## 2. Бизнес-требования

| ID    | Бизнес-требование                                                                                                                          | Основа                     |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------- |
| BR-01 | Нужна соревновательная игра для 2–4 человек (матчи 1×1 и 2×2), которые стоят у одного стола и видят арену на нём в дополненной реальности. | The Machines, Spaceteam    |
| BR-02 | Игра должна работать в одной локальной сети Wi-Fi без доступа в интернет и без аккаунтов.                                                  | Недостаток Minecraft Earth |
| BR-03 | Игра должна воспроизводить механику Pudge Wars — дуэль на крюках через реку с золотом и улучшениями — без персонажей и ассетов Dota 2.     | Pudge Wars                 |
| BR-04 | Матч должен длиться не дольше 10 минут.                                                                                                    | Недостаток Angry Birds AR  |

## 3. Функциональные требования

| ID    | Функциональное требование                                                                                                              | Основа         |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| FR-01 | Игрок должен иметь возможность создать игру из главного меню; его телефон становится хостом.                                           | Mirror         |
| FR-02 | Игрок должен иметь возможность подключиться к игре по IP-адресу хоста, который показан в лобби.                                        | Mirror         |
| FR-03 | В лобби игрок выбирает команду и нажимает «Готов»; хост может начать матч, когда все игроки готовы.                                    | MOBA           |
| FR-04 | Приложение должно находить горизонтальную поверхность и ставить арену в точку тапа.                                                    | Angry Birds AR |
| FR-05 | До подтверждения установки игрок должен иметь возможность менять масштаб арены двумя пальцами.                                         | The Machines   |
| FR-06 | Каждый игрок ставит арену на своём телефоне сам; совмещение арен между телефонами не требуется.                                        | новое          |
| FR-07 | Тап по своей половине арены должен отправлять героя в эту точку; перейти реку герой не может.                                          | Pudge Wars     |
| FR-08 | Свайп от своего героя должен бросать крюк в направлении свайпа; следующий бросок доступен после перезарядки.                           | Wild Rift      |
| FR-09 | Попадание крюком во врага должно наносить урон и притягивать его к бросившему; попадание в союзника — притягивать без урона.           | Pudge Wars     |
| FR-10 | Герой с нулевым здоровьем должен погибать и возрождаться на своей половине через несколько секунд.                                     | Pudge Wars     |
| FR-11 | За убийство игрок должен получать золото и тратить его в магазине на улучшение дальности и урона крюка.                                | Pudge Wars     |
| FR-12 | Матч должен заканчиваться победой команды, первой набравшей заданное число убийств, или по таймеру — победой команды с большим счётом. | Pudge Wars     |
| FR-13 | Во время матча на экране должны отображаться здоровье, перезарядка крюка, золото, счёт команд и оставшееся время.                      | Brawl Stars    |
| FR-14 | После матча должен показываться экран результатов с победителем и кнопками «Реванш» и «В меню».                                        | MOBA           |
| FR-15 | Исход действий должен определять хост: перемещение за реку и бросок на перезарядке, отправленные клиентом, отклоняются.                | Mirror         |

## 4. Нефункциональные требования

| ID     | Нефункциональное требование                                                                                                           | Проверка                               |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| NFR-01 | Матч 2×2 на телефонах в одной сети Wi-Fi должен проходить от лобби до экрана результатов без падения приложения и разрыва соединения. | Прогон матча на двух и более телефонах |
| NFR-02 | Частота кадров в матче на тестовом телефоне с ARCore — не ниже 20 FPS.                                                                | Счётчик FPS в отладочном оверлее       |
| NFR-03 | Время от запуска приложения до главного меню — не больше 15 с.                                                                        | Секундомер на тестовом телефоне        |
