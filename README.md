# Pudge Wars AR

LAN-дуэль на хуках в AR для Android/ARCore. Unity 6000.6.5f1, URP.

Источники требований и архитектуры: [ТДД](Docs/pudge_wars_ar_tdd.md) и [чек-лист](Docs/pudge_wars_ar_checklist.md).

## Этап 0 — завершён

Добавлены шесть игровых конфигов с readonly-снимками данных, регистрации в ProjectScope, версия протокола 1, development-оверлей FPS/версии. Есть загрузка сцен, DI, экран загрузки, логирование и распознавание жестов. Обработана отмена переходов экрана загрузки; запущенные Unity-операции сцен завершаются до передачи отмены.

Ручные проверки этапа 0 подтверждены разработчиком; все пункты отмечены в чек-листе.

Оверлей: `Assets/Game/Prefabs/UI/Development Overlay.prefab`, экземпляр в Boot. В Prefab Mode можно менять оформление TMP и Canvas, а на DevelopmentOverlay — интервал обновления. FPS усредняется по unscaled-времени; оверлей работает в редакторе и development-сборках, в обычной сборке выключается.

Для проверки:

1. Открыть проект и запустить Play Mode из любой сцены: ожидается Boot → Main Menu.
2. Перейти кнопкой в Gameplay; проверить отсутствие ошибок, оверлей и логирование кликов/жестов.
3. В Android Build Profile включить Development Build, пройти XR Project Validation, собрать APK.
4. Установить APK на ARCore-совместимый телефон: проверить меню, FPS/версию и подключение Profiler.
5. После приёмки завершить чек-лист и поставить тег v0.0-skeleton.

EditMode-тесты: через Test Runner открытого редактора либо при закрытом редакторе:

```text
unity test --mode EditMode
```

## Этап 1 — первый играбельный прототип

Запуск: Play Mode → Main Menu → Gameplay. Синий герой управляется игроком, оранжевый — манекен.

- Тап по столу перемещает героя; цель ограничивается своей половиной.
- Свайп от синего героя показывает прицел; отпускание бросает хук. Возврат пальца к герою отменяет бросок.
- Попадание снимает 175 HP и притягивает манекен; после возврата хука начинается перезарядка 3 с.
- Манекен автоматически восстанавливается через 2 с после попадания, когда хук уже вернулся. Reset training сбрасывает песочницу, Back to menu возвращает в меню.

Симуляция работает на 30 Гц, отображение интерполируется между тиками. Песочница активна в Editor и Development Build. Проверены 62 EditMode-теста и ввод через виртуальный Touchscreen в Play Mode. Сеть, экономика, правила матча и AR-размещение ещё не подключены. Gizmos и настраиваемый лимит FPS реализованы; до закрытия этапа 1 остаются ручная приёмка и тег v0.1-core.


Для проверки этапа 1: в Play Mode выбери ArenaRoot и включи Gizmos в Scene или Game view. На OfflineSimulationDriver флаг Draw Simulation Gizmos показывает границы и хитбоксы, Frame Rate Limit задаёт лимит FPS (например, 20). Значение 0 восстанавливает прежние FPS/VSync. Проверь движение, бросок, попадание, отмену свайпа и игнорирование касаний над UI. Симуляция всегда работает на 30 Гц. Коммит и тег этапа ставятся после ручной приёмки.
